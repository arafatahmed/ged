# GED

Plateforme de gestion électronique de documents pour une institution publique : Django 5.2 et PostgreSQL 16 pour l'API, Angular 21 pour l'interface, en français et en arabe.

| Dossier | Contenu |
|---|---|
| [`ged/`](ged/README.md) | Code de l'application : API Django, interface Angular (`ged/frontend/`), déploiement Docker et Nginx |
| [`docs/ged/`](docs/ged/README.md) | Cadrage, conception et comptes rendus des lots |

Installation et commandes : voir [`ged/README.md`](ged/README.md).

Ce dépôt reprend l'application développée dans le sous-dossier `ged/` du dépôt `enajm-grh` (hypothèse H2 : dépôt dédié), avec un historique neuf : l'historique d'origine contenait des données du personnel qui ne concernent pas la GED.
